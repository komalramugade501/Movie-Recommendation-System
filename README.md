# Movie Recommendation System

A content-based movie recommendation system that recommends movies with similar genres and keywords using TF-IDF and cosine similarity.

## Technologies
Python, Pandas, Scikit-learn, TF-IDF, Cosine Similarity

## Run
```bash
pip install -r requirements.txt
python recommend.py
```

Change `movie_name` in `recommend.py` to try another movie.
